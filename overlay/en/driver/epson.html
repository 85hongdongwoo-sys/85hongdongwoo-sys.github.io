    Very detailed guide for first-timers

    In 3 lines
    ① Find your printer's model name. ② Click the blue button for your model on this page. ③ Open the file and keep clicking Next.

    1. Windows or Mac?

    • A window-shaped Start button at the bottom of the screen means Windows.
    • An apple logo at the top-left means Mac.
    • To check 64-bit: Settings → System → About → System type. Almost all recent PCs are 64-bit.

    2. Find your Epson model name

    • Look on the front or top of the printer.
    • Or check the label on the back or bottom, next to "Model".
    • If it was installed before, it may appear in Settings → Bluetooth & devices → Printers & scanners.
    • Typing just the numbers in the search box works too.

    3. Where does the download go?

    • Chrome and Edge show a download arrow (↓) at the top-right.
    • Press Ctrl + J to open your downloads, or open File Explorer → Downloads.
    • Files over 100 MB can take a few minutes. Keep the window open.

    If you downloaded a .zip file

    1. Right-click the .zip file.
    2. Choose Extract All… and then Extract.
    3. Open the new folder and double-click SETUP.EXE (or a file starting with Setup / Install).

    4. Buttons you will see

    • Yes on "Do you want to allow this app to make changes?" — it is the official file.
    • I agree — accept the license to continue.
    • Next — if unsure, keep the default choice and press Next.
    • Install → wait → Finish.

    5. USB or Wi-Fi?

    • USB: one cable, easiest, best for one computer.
    • Wi-Fi / network: no cable, many devices can share it. The printer and computer must be on the same router (same Wi-Fi).

    6. After installing

    • Print test page: Settings → Bluetooth & devices → Printers & scanners → your printer → Print test page.
    • Make it default: on the same screen, press Set as default (turn off "Let Windows manage my default printer" if the button is missing).
    • "Offline"? Check power and cable/Wi-Fi, turn the printer off and on, then restart the PC.

    Try first: Windows automatic install

    Windows often installs a printer driver by itself.

    • Go to Settings → Bluetooth & devices → Printers & scanners and press Add device.
    • Microsoft recommends getting drivers through Windows Update.
    • If that does not work, download the latest software from the maker's official site (this page).
