    Try first: Windows automatic install

    Windows often installs a printer driver by itself.

    • Go to Settings → Bluetooth & devices → Printers & scanners and press Add device.
    • Microsoft recommends getting drivers through Windows Update.
    • If that does not work, download the latest software from the maker's official site (this page).

    Avoid fake driver sites

    Do not install "driver updater" programs from ads or files posted on blogs — they may add unwanted software. Use the maker's official site or Windows Update.
