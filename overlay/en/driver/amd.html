AMD Radeon & Ryzen Chipset Drivers — Download & Install

The easiest way is AMD's Auto-Detect and Install tool.

Steps

1Find your graphics card

Right-click Start → Device Manager → Display adapters.

2Download Auto-Detect and Install

On any AMD product page, under Windows 10/11, click Download Auto-Detect and Install (a small tool). It detects your graphics card and Windows version and installs the matching official driver.

3Run, click Yes, follow the tool

Open the file, click Yes, and let the tool install AMD Software: Adrenalin Edition.
