    How to install

    1. Microsoft recommends Windows Update: Settings → Windows Update → Check for updates, then install optional driver updates named Surface.
    2. To install manually, run winver to see your build, then download the .msi whose build number is equal to or lower than yours.
    3. Before updating: connect accessories, plug in power, charge to 40%+, use a stable connection.
