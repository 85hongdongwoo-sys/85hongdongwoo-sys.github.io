LG gram: install with LG Update

  1. Click Download LG Update (LG Update integrated launcher, straight from LG).
  2. Extract the file, then run LG Update Installer.
  3. Click OK when it says it will install the LG Update app for your system.
  4. Tick Run LG Update, click Finish, then install everything in the update list.

An internet connection is required. If Wi-Fi/LAN is missing after reinstalling Windows, download your model's LAN/WLAN driver below on another PC first.
