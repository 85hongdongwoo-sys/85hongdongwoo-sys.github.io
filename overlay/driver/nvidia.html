엔비디아(NVIDIA) 그래픽 드라이버 다운로드·설치 방법

지포스(GeForce)·RTX 그래픽카드 드라이버를 공식 사이트에서 받아 설치하는 순서를 그림으로 쉽게 정리했어요.

엔비디아(NVIDIA) 그래픽 드라이버는 NVIDIA 공식 드라이버 페이지에서 받아요. 제품 범주 → 제품 시리즈 → 제품 → 운영 체제를 고르고 [Find Drivers]를 누른 뒤 [다운로드]하면 돼요. 매번 찾기 귀찮다면 NVIDIA App을 깔면 새 드라이버가 나올 때 알림을 받고 바로 업데이트할 수 있어요.

그림으로 보는 설치 순서

1내 그래픽카드 이름 확인

시작 버튼을 마우스 오른쪽으로 누르고 → 장치 관리자 → 디스플레이 어댑터를 펼치면 그래픽카드 이름이 나와요. 노트북은 두 개(인텔 + 엔비디아 등)가 보일 수 있어요.

2드라이버 페이지에서 내 제품 고르기

NVIDIA 드라이버 페이지의 수동 검색에서 제품 범주, 제품 시리즈, 제품, 운영 체제, 언어, 다운로드 유형을 차례로 고르고 [Find Drivers]를 눌러요.

다운로드 유형: 게임을 주로 하면 Game Ready, 영상 편집·디자인 프로그램을 주로 쓰면 Studio를 고르세요.

4다운로드하고 실행

결과에서 [다운로드]를 누르고, 받은 파일을 Ctrl + J로 열어 실행해요.

5'예' 누르고 설치

윈도우 확인 창에서 [예]를 누르고, 설치 프로그램 안내대로 진행해요. 설치 중 화면이 잠깐 깜빡이는 건 정상이에요.

자동으로 받기: NVIDIA App

NVIDIA 공식 안내에 따르면 NVIDIA App을 설치하면 새 드라이버가 나올 때 자동 알림을 받고, 클릭 한 번으로 바로 업데이트할 수 있어요.

자주 묻는 질문

Game Ready와 Studio 드라이버는 뭐가 달라요?
NVIDIA 안내에 따르면 Game Ready는 주요 게임에, Studio는 주요 크리에이티브(영상·디자인) 앱에 맞춰진 드라이버예요. 잘 모르겠으면 평소 많이 하는 쪽을 고르세요.
내 그래픽카드가 엔비디아인지 어떻게 알아요?
시작 버튼 오른쪽 클릭 → 장치 관리자 → 디스플레이 어댑터에서 이름을 보세요. GeForce, RTX, GTX 같은 이름이면 엔비디아예요.
드라이버는 무료인가요?
네. NVIDIA 공식 사이트의 드라이버는 무료예요.
리눅스는요?
NVIDIA 안내에 따르면 리눅스는 배포판이 제공하는 패키지를 쓰는 걸 권장해요.

출처와 안내

출처: NVIDIA 공식 드라이버 페이지(nvidia.com/ko-kr/geforce/drivers), Microsoft 지원 · 확인 2026년 11월 22일.
홍라이프 도구는 드라이버 파일을 직접 올리지 않아요. 모든 다운로드는 제조사 공식 사이트에서 이루어져요. 그림은 이해를 돕기 위해 단순하게 그린 것이라 실제 화면과 다를 수 있어요.
