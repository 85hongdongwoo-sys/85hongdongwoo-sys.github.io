큐냅(QNAP) NAS 설치 프로그램 다운로드 — Qfinder Pro, Qsync

큐냅 큐냅 NAS를 찾고 연결하는 Qfinder Pro, PC 파일 동기화 Qsync 같은 공식 프로그램을 받는 방법이에요.

큐냅 NAS는 Qfinder Pro로 같은 공유기에 연결된 NAS를 찾아 연결해요. PC 파일 자동 동기화는 Qsync, 윈도우 PC 통째 백업은 HDP PC Agent를 써요. 큐냅은 가짜 Qfinder Pro 사이트를 주의하라고 공지했으니 꼭 공식 주소(download.qnap.com)에서 받으세요.

공식 프로그램·드라이버 받기

  • Qfinder Pro (NAS 찾기·연결)

    같은 랜(LAN)의 큐냅 NAS를 찾아 접속해요. 윈도우용은 NAS를 네트워크 드라이브로 연결하는 기능도 있어요. 버전 7.14.1.

    윈도우용 바로 받기download.qnap.com · .exe맥용 바로 받기download.qnap.com · .dmg

  • Qsync (PC·NAS 파일 동기화)

    PC의 Qsync 폴더와 NAS를 자동으로 맞춰요. 필요한 폴더만 동기화할 수도 있어요.

    Qsync 윈도우용 바로 받기download.qnap.com · .exeQsync 맥용 바로 받기download.qnap.com · .dmg

  • HDP PC Agent (윈도우 PC 백업) · 전체 유틸리티

    윈도우 PC·서버의 앱·설정·데이터를 NAS로 백업해요. 다른 큐냅 프로그램은 유틸리티 페이지에 모두 있어요.

    HDP PC Agent 바로 받기download.qnap.com · .exe큐냅 유틸리티 전체 보기qnap.com · 한국어

설치 순서 (아주 쉽게)

  1. 내 운영체제에 맞는 Qfinder Pro를 받아 설치해요.
  2. PC와 NAS를 같은 공유기에 연결하고 Qfinder Pro를 열면 NAS가 목록에 나와요.
  3. 처음 설치라면 목록의 NAS를 눌러 안내대로 운영체제(QTS·QuTS hero)를 설치해요.
  4. 파일 동기화가 필요하면 Qsync를 설치하고 NAS 주소와 계정을 넣어요(비밀번호는 본인이 직접).

꼭 알아 둘 것

  • 큐냅 공식 공지: 가짜 Qfinder Pro 다운로드 사이트가 발견됐어요. 검색 광고 말고 qnap.com·download.qnap.com에서만 받으세요.
  • 버전 번호가 붙은 바로 받기 파일이 바뀌면 '큐냅 유틸리티 전체 보기'에서 최신 버전을 받으세요.

내 제품 모델명 찾기

  • NAS 뒷면·바닥 스티커에 모델명(예: TS-264)과 일련번호가 있어요.
  • Qfinder Pro 목록에도 모델명이 나와요.

처음 하는 분을 위한 아주 자세한 안내

3줄 요약
① 내 제품 모델명을 확인해요. ② 이 페이지의 파란 버튼으로 공식 앱이나 파일을 받아요. ③ 앱에서 업데이트 확인 → 설치를 누르고, 다시 시작하라고 하면 다시 시작해요.

1. 내 윈도우 버전 확인하기

  • 설정 → 시스템 → 정보에서 윈도우 사양(예: Windows 11, 버전 24H2)과 시스템 종류(64비트)를 볼 수 있어요.
  • 작업표시줄 검색에 winver를 쳐도 버전이 나와요.

2. 내 큐냅 제품 모델명 찾기

  • 노트북은 바닥면 스티커나 새겨진 글자, 모니터는 뒷면 스티커를 보세요.
  • 윈도우 설정 → 시스템 → 정보에도 장치 이름이 나와요.

3. Microsoft Store 앱 설치하기

  • 파란 버튼을 누르면 Microsoft Store 페이지가 열려요. [받기] 또는 [스토어 앱에서 보기] → [받기]를 눌러요.
  • 설치가 끝나면 작업표시줄 검색에서 앱 이름을 쳐서 열어요.

4. 파일(.exe)을 받았다면

  • 키보드 Ctrl + J로 받은 파일을 열어요. "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?"에는 [예]를 눌러요.
  • 설치 화면은 [다음] → [설치] → [마침] 순서예요.

5. 업데이트할 때 꼭 지킬 것

  • 노트북은 충전기를 꽂고 하세요.
  • BIOS(바이오스)·펌웨어 업데이트 중에는 절대 전원을 끄거나 덮개를 닫지 마세요.
  • 여러 개를 설치한 뒤에는 다시 시작해야 적용되는 경우가 많아요.

자주 묻는 질문

큐냅 NAS 프로그램는 어디서 받아야 안전해요?
큐냅 공식 사이트·공식 앱 스토어에서 받으세요. 이 페이지의 버튼은 모두 큐냅 공식 주소로 연결돼요. 광고에 나오는 '드라이버 자동 설치' 프로그램은 쓰지 마세요.
Qfinder Pro를 아무 데서나 받아도 되나요?
안 돼요. 큐냅이 가짜 Qfinder Pro 사이트를 경고했어요. qnap.com이나 download.qnap.com에서만 받으세요.
파일은 어디서 받아지나요?
큐냅 공식 서버나 공식 앱 스토어에서 받아져요. 홍라이프 도구는 파일을 올리지 않아요.

홍라이프 도구는 드라이버 파일을 직접 올리지 않아요. 모든 다운로드는 제조사 공식 사이트에서 이루어져요. 그림은 이해를 돕기 위해 단순하게 그린 것이라 실제 화면과 다를 수 있어요.
