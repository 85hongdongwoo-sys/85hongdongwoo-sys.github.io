애플 드라이버·프로그램 다운로드 — 윈도우에서 아이폰 연결(Apple 기기 앱)·iCloud·Boot Camp

윈도우 PC에 아이폰·아이패드를 연결하는 Apple 기기 앱, Windows용 iCloud, iTunes, 인텔 맥의 Boot Camp 지원 소프트웨어를 Apple 공식 경로로 받고 쉽게 설치하는 방법이에요.

윈도우 PC에서 아이폰·아이패드를 연결하려면 Apple 기기 앱(Microsoft Store, 무료)을 설치하면 돼요. 아이폰을 연결하는 드라이버도 이 앱과 함께 들어가요. 사진·파일을 PC와 맞추려면 Windows용 iCloud, 인텔 맥에 윈도우를 깔았다면 Boot Camp 지원 소프트웨어(Windows 지원 소프트웨어)를 받아요.

그림으로 보는 아이폰 연결 순서 (윈도우)

1Microsoft Store에서 받기

위 [Apple 기기 앱 받기]를 누르면 Microsoft Store 페이지가 열려요. [받기](또는 [Store 앱에서 받기])를 눌러 설치해요.

2아이폰을 USB로 연결

Apple 기기 앱을 열고 아이폰을 USB 케이블로 PC에 연결해요.

3아이폰에서 '신뢰' 누르기

아이폰 화면에 '이 컴퓨터를 신뢰하겠습니까?'가 뜨면 [신뢰]를 누르고 암호를 넣어요. 그러면 앱 왼쪽 목록에 내 아이폰이 나타나요.

Boot Camp 지원 소프트웨어 받고 설치하기 (인텔 맥)

  1. 16GB 이상 USB 메모리를 맥에 꽂고, 디스크 유틸리티로 MS-DOS(FAT), 마스터 부트 레코드 방식으로 포맷해요.
  2. 인터넷에 연결하고 응용 프로그램 → 유틸리티 → Boot Camp 지원 앱을 열어요.
  3. 메뉴 막대의 동작 → Windows 지원 소프트웨어 다운로드를 고르고, 저장 위치로 그 USB를 골라요. 다 받으면 Boot Camp 지원 앱을 닫아요.
  4. USB를 꽂은 채로 맥을 윈도우로 시작해요.
  5. 파일 탐색기에서 USB → WindowsSupport 또는 BootCamp 폴더의 Setup(setup.exe)을 열고, 변경 허용 창에서 [예]를 눌러요.
  6. [복구]를 눌러 설치를 시작해요. 'Windows 로고 테스트를 통과하지 않았다'는 경고가 나오면 [계속]을 눌러요.
  7. [완료]를 누르고, 다시 시작하라고 하면 맥을 다시 시작해요.

출처: Apple 지원 'Mac에 Windows 지원 소프트웨어 다운로드 및 설치'. 지원되는 맥 모델과 윈도우 버전은 Apple의 시스템 요구 사항 문서에서 확인하세요.

PC가 아이폰을 못 알아볼 때

  • 먼저 Apple 기기 앱을 연 다음 아이폰을 연결하고, 아이폰의 '신뢰'를 눌렀는지 확인해요.
  • 충전만 되는 케이블일 수 있어요. 데이터 전송이 되는 다른 케이블로 바꿔 보세요. 아이폰 충전 단자에 먼지가 없는지도 봐요.
  • 다른 USB 포트나 다른 PC에 꽂아 봐요.
  • 윈도우 업데이트와 아이폰 iOS 업데이트를 최신으로 해요.
  • 그래도 안 되면 Apple 지원에 문의하세요.

먼저 해 볼 것: 윈도우 자동 설치

요즘 윈도우는 프린터를 연결하면 드라이버를 스스로 찾아 설치하는 경우가 많아요. 제조사 사이트에 가기 전에 한 번 해 보세요.

  • 설정 → Bluetooth 및 장치 → 프린터 및 스캐너에서 [장치 추가]를 눌러 프린터를 추가해요.
  • Windows 업데이트로 드라이버를 받는 방법을 Microsoft가 권장해요.
  • 그래도 안 되면 제조사 공식 사이트에서 모델명을 검색해 윈도우 버전에 맞는 최신 소프트웨어를 받아요(이 페이지의 방법).

자주 묻는 질문

아이폰 드라이버는 따로 받아야 하나요?
아니요. 윈도우 PC는 Apple 기기 앱을 설치하면 아이폰 연결에 필요한 것이 함께 설치돼요. 따로 '아이폰 드라이버'를 주는 사이트는 조심하세요.
iTunes와 Apple 기기 앱 중 뭘 써요?
새로 시작한다면 Apple 기기 앱을 쓰세요. 음악·영상 동기화에는 Apple Music, Apple TV 앱도 설치돼 있어야 해요(Apple 안내).
맥(Mac)은 드라이버를 어디서 받아요?
맥은 macOS 업데이트(시스템 설정 → 일반 → 소프트웨어 업데이트)로 드라이버가 함께 업데이트돼요. 프린터 등 다른 회사 기기는 이 사이트의 각 회사 페이지를 보세요.
Apple 실리콘(M1·M2…) 맥에서도 Boot Camp를 쓸 수 있나요?
Boot Camp 지원은 인텔 프로세서 맥용이에요. 지원 여부는 Apple의 Boot Camp 시스템 요구 사항 문서에서 내 맥 모델을 확인하세요.
모두 무료인가요?
네. Apple 기기, iCloud, iTunes, Boot Camp 지원 소프트웨어 모두 무료예요.
