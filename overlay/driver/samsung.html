삼성 드라이버 다운로드 — 갤럭시 북 모델명별 설치, 프린터·모니터·SSD·USB

홍라이프 도구 편집팀 · 마지막 확인 2026년 11월 23일 · 삼성전자서비스·HP·삼성 반도체 공식 안내 기준

삼성 노트북(갤럭시 북6·5·4·3·2·프로·플렉스·이온), 삼성 프린터, 모니터, SSD, 갤럭시 휴대폰 USB 드라이버를 모델명으로 찾아서 공식 앱과 공식 사이트에서 받는 방법을 정리했어요.

한 줄 답: 갤럭시 북은 윈도우 11이면 디바이스 케어 → [업데이트] → [업데이트 확인] → [모두 업데이트], 예전 윈도우 10이면 Samsung Update, NT750XFG 같은 일부 모델은 Windows 업데이트로 받아요. 삼성 프린터는 HP 고객지원, SSD는 Samsung Magician이에요.

모델명으로 삼성 드라이버 찾기

노트북 바닥면이나 모니터 뒷면의 모델명을 넣으면 맞는 방법을 알려 줘요. 앞 8자리만 넣어도 돼요. 예: NT940XHA, NT750XFG, SL-M2020W, MZ-V9P1T0, SM-S928

모델명을 넣으면 여기에 결과가 나와요.

갤럭시 북 시리즈별 모델명과 드라이버 받는 곳

삼성 노트북은 모델명 앞부분(예: NT940XHA)으로 시리즈를 알 수 있어요. 아래 표는 삼성전자서비스가 시리즈별로 안내하는 모델명을 모은 거예요. 모델명 뒤의 -KC71G 같은 글자는 색상·CPU·저장 용량 차이라서 드라이버는 앞부분이 같으면 같아요.

Samsung Update를 지원하지 않는 모델 (Windows 업데이트로 설치)

아래 모델은 Samsung Update로 드라이버를 받을 수 없어요. 설정 → Windows 업데이트 → [업데이트 확인], 그리고 고급 옵션 → 선택적 업데이트에서 드라이버를 받아요.

  • NT550XDA · NT750XDA · NT755XDA · NT750XED · NT750XEE · NT750XFG · NT750XFH · DM530AFA · DB531AFA 로 시작하는 모델 (갤럭시 북·북2·북3 일반 모델, 데스크톱 일부)
  • SM-W737 · SM-W767 · DM530ABE 등

삼성전자서비스 ‘노트북 장치 드라이버 설치 및 업데이트 방법’의 Windows 업데이트 전용 모델 안내 기준이에요. 목록은 바뀔 수 있으니 모델이 안 보이면 디바이스 케어부터 열어 보세요.

삼성 노트북(갤럭시 북) — 내 윈도우에 맞는 방법 고르기

  • 윈도우 11 갤럭시 북 → 디바이스 케어 (추천)

    윈도우 11이나 윈도우 10 22H2 갤럭시 북은 디바이스 케어로 드라이버를 업데이트해요. 작업표시줄 검색에 디바이스 케어를 쳐서 열고, 없으면 Microsoft Store에서 설치해요.

    Microsoft Store에서 디바이스 케어 찾기삼성 공식 앱 · 무료

  • 예전 윈도우 10 노트북 → Samsung Update

    디바이스 케어 이전 노트북은 Samsung Update 앱으로 드라이버·BIOS·삼성 앱을 받아요. 윈도우 11 25H2 이상에서는 Samsung Update가 지원되지 않아요(디바이스 케어를 쓰세요).

    Samsung Update 받기Microsoft Store · 삼성 공식

  • 갤럭시 북2 이후 → 갤럭시 북 다운로드 센터

    앱 없이 파일로 받고 싶으면 갤럭시 북 다운로드 센터에서 모델 번호를 검색해 윈도우 11 드라이버·매뉴얼을 직접 받아요(갤럭시 북2 시리즈부터).

    갤럭시 북 다운로드 센터samsung.com · 모델 번호로 찾기

  • 윈도우 7·8 옛날 노트북 → 다운로드 자료실

    삼성전자서비스 다운로드 자료실에서 모델명을 검색해 드라이버를 하나씩 받아요. 윈도우 8·8.1용 Samsung Update 프로그램도 [유용한 소프트웨어 → PC/프린터]에 있어요.

    삼성전자서비스 다운로드 자료실모델명으로 찾기

디바이스 케어로 드라이버 업데이트 (아주 쉽게)

  1. 노트북에 충전기를 꽂아요. 배터리가 30% 이하면 업데이트가 진행되지 않아요.
  2. 작업표시줄 검색에 디바이스 케어를 쳐서 열어요(없으면 위 버튼으로 Microsoft Store에서 설치).
  3. 왼쪽 메뉴에서 [업데이트]를 누르고, 오른쪽 위 [업데이트 확인]을 눌러요.
  4. 설치할 수 있는 드라이버 목록이 나오면 오른쪽 위 [모두 업데이트]를 눌러요.
  5. "PC를 다시 시작할까요?"가 나오면 [네]를 눌러 다시 시작해요. BIOS 업데이트 중에는 절대 전원을 끄지 마세요.

Samsung Update를 쓰는 노트북: 앱을 열고 [드라이버] → 설치 가능 항목의 [설치] 또는 오른쪽 위 [모두 업데이트]. 삼성 소프트웨어는 왼쪽 위 [삼성 앱스]에서 받아요.

삼성 프린터 드라이버 (SL-M2020·M2070·C480 등) — HP에서 받아요

삼성 프린터 사업은 HP가 인수해서, 지금은 삼성 프린터의 드라이버·지원·보증을 HP가 맡고 있어요. 삼성전자 고객지원도 M2070 같은 삼성 프린터는 HP 사이트에서 지원받으라고 안내해요.

  1. HP 고객지원 드라이버 페이지를 열어요.
  2. [프린터]를 고르고, 프린터 앞면 라벨의 모델명을 Samsung Xpress SL-M2020처럼 넣어요.
  3. 내 운영체제(윈도우 11 등)를 확인하고 전체 소프트웨어(설치 프로그램) 또는 프린트 드라이버를 받아요.
  4. 설치 프로그램을 실행해 USB나 Wi-Fi로 연결해요.

삼성 SSD 드라이버 — Magician과 NVMe 드라이버 3.3

삼성 SSD는 대부분 따로 드라이버를 깔 필요가 없어요. 펌웨어 업데이트와 상태 확인은 Samsung Magician으로 해요. 삼성 NVMe 드라이버 3.3은 970 PRO·970 EVO·970 EVO Plus·960 PRO·960 EVO·950 PRO만 지원하고, 윈도우 7·8.1·10용이에요. 980·990 시리즈는 윈도우 기본 NVMe 드라이버를 쓰면 돼요.

삼성 모니터·갤럭시 USB 드라이버

  • 삼성 모니터

    모니터는 연결하면 윈도우가 대부분 알아서 인식해요. 화면 나누기 프로그램 Easy Setting Box 같은 모니터 프로그램은 다운로드 자료실에서 모델명 검색 → [응용프로그램]에서 내 운영체제용을 받아요(윈도우 7~11, macOS 12 이상). 지원하지 않는 모델은 목록에 안 나와요. 오디세이·스마트 모니터처럼 모델명이 LS27, LS32, LC27 등으로 시작하는 제품도 같은 방법이에요.

    다운로드 자료실에서 모니터 모델 찾기삼성전자서비스 공식

  • 갤럭시 휴대폰 USB 드라이버 (윈도우)

    갤럭시 휴대폰·태블릿을 윈도우 PC에 USB로 연결해 개발(안드로이드 스튜디오 등)할 때 필요한 삼성 공식 드라이버예요. 버전 1.9.5.0 · 35.5MB · 2026-05-06. 사진 옮기기만 할 때는 보통 필요 없어요.

    USB 드라이버 바로 받기삼성 개발자 사이트 서버 · 윈도우삼성 개발자 안내 페이지developer.samsung.com

내 제품 모델명 찾기

  • 노트북 바닥면에 새겨진(레이저 각인) 모델명을 봐요.
  • 2016년 이후 노트북은 전원을 켜고 삼성 로고가 나오기 전에 F6 키를 5번쯤 누르면 제품 정보의 Model Name이 보여요.
  • 모니터는 뒷면 스티커에서 모델명을 봐요.

처음 하는 분을 위한 아주 자세한 안내

3줄 요약
① 내 제품 모델명을 확인해요. ② 이 페이지의 파란 버튼으로 공식 앱이나 파일을 받아요. ③ 앱에서 업데이트 확인 → 설치를 누르고, 다시 시작하라고 하면 다시 시작해요.

1. 내 윈도우 버전 확인하기

  • 설정 → 시스템 → 정보에서 윈도우 사양(예: Windows 11, 버전 24H2)과 시스템 종류(64비트)를 볼 수 있어요.
  • 작업표시줄 검색에 winver를 쳐도 버전이 나와요.

2. 내 삼성 제품 모델명 찾기

  • 노트북은 바닥면 스티커나 새겨진 글자, 모니터는 뒷면 스티커를 보세요.
  • 윈도우 설정 → 시스템 → 정보에도 장치 이름이 나와요.

3. Microsoft Store 앱 설치하기

  • 파란 버튼을 누르면 Microsoft Store 페이지가 열려요. [받기] 또는 [스토어 앱에서 보기] → [받기]를 눌러요.
  • 설치가 끝나면 작업표시줄 검색에서 앱 이름을 쳐서 열어요.

4. 파일(.exe)을 받았다면

  • 키보드 Ctrl + J로 받은 파일을 열어요. "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?"에는 [예]를 눌러요.
  • 설치 화면은 [다음] → [설치] → [마침] 순서예요.

5. 업데이트할 때 꼭 지킬 것

  • 노트북은 충전기를 꽂고 하세요.
  • BIOS(바이오스)·펌웨어 업데이트 중에는 절대 전원을 끄거나 덮개를 닫지 마세요.
  • 여러 개를 설치한 뒤에는 다시 시작해야 적용되는 경우가 많아요.

먼저 해 볼 것: Windows 업데이트

윈도우는 많은 드라이버를 Windows 업데이트로 자동으로 받아요.

  • 설정 → Windows 업데이트 → [업데이트 확인]을 눌러요.
  • 고급 옵션 → 선택적 업데이트에 드라이버 업데이트가 따로 있을 수 있어요.
  • 그래도 안 되면 제조사 공식 앱·사이트에서 받아요(이 페이지의 방법).

자주 묻는 질문

삼성 노트북 드라이버는 어디서 받아요?
윈도우 11 갤럭시 북은 디바이스 케어 앱의 [업데이트] → [업데이트 확인] → [모두 업데이트]로 받아요. 2017년 8월 이후 윈도우 10 노트북은 Microsoft Store의 Samsung Update 앱, 그 이전 윈도우 7·8 노트북은 삼성전자서비스 다운로드 자료실의 Samsung Update 프로그램을 써요.
내 노트북이 갤럭시 북 몇인지 모르겠어요.
노트북 바닥의 모델명 앞 8자리를 이 페이지의 ‘모델명으로 찾기’에 넣으세요. 예를 들어 NT940XHA는 갤럭시 북5 Pro, NT960XGK는 갤럭시 북4 Pro, NT750XFG는 갤럭시 북3예요.
Samsung Update에 드라이버가 안 나와요.
NT750XDA, NT750XED, NT750XEE, NT750XFG, NT750XFH처럼 Samsung Update를 지원하지 않는 모델은 Windows 업데이트(선택적 업데이트 포함)로 드라이버를 받아요. 윈도우 11 25H2 이상에서는 디바이스 케어를 쓰세요.
윈도우를 새로 깔았는데 와이파이가 안 돼요.
인터넷이 되는 다른 PC에서 갤럭시 북 다운로드 센터(북2 이후)나 Samsung Update의 [다운로드] 메뉴로 무선랜 드라이버를 받아 USB에 옮겨 설치해요.
갤럭시 북 다운로드 센터는 어떤 모델이 되나요?
갤럭시 북2 시리즈 이후 모델의 윈도우 11 드라이버를 제공해요. 그 이전 모델은 Samsung Update나 다운로드 자료실을 쓰세요.
삼성 프린터 SL-M2020 드라이버는 어디 있어요?
삼성 프린터 지원은 HP가 맡고 있어요. HP 고객지원(support.hp.com)에서 ‘Samsung Xpress SL-M2020’을 검색해 받으세요. 모델 페이지에 없으면 Samsung Universal Print Driver 3를 써요.
삼성 SSD 드라이버를 꼭 깔아야 하나요?
아니요. 970 EVO Plus 이하 일부 모델만 삼성 NVMe 드라이버 3.3을 쓸 수 있고, 980·990 시리즈는 윈도우 기본 드라이버로 충분해요. 펌웨어 업데이트는 Samsung Magician으로 해요.
삼성 모니터 드라이버와 Easy Setting Box는요?
모니터는 연결하면 대부분 윈도우가 자동으로 인식해요. 화면 분할 프로그램 Easy Setting Box는 삼성전자서비스 다운로드 자료실에서 모델명을 검색해 [응용프로그램]에서 받아요(윈도우 7~11, macOS 12 이상).
갤럭시 휴대폰을 PC에 연결하려면 드라이버가 필요해요?
사진·파일 옮기기는 보통 필요 없어요. 안드로이드 개발(ADB)을 할 때만 삼성 Android USB 드라이버를 깔아요.
업데이트가 진행되지 않아요.
충전기를 꽂았는지, 배터리가 30%보다 많은지 확인하세요. BIOS 업데이트 중에는 전원을 끄거나 덮개를 닫지 마세요.
