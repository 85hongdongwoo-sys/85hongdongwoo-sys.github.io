    시작 전에 알아 두기

    ?드라이버가 뭐예요?

    드라이버는 기기와 컴퓨터를 이어 주는 통역 프로그램이에요. 프린터를 USB로 꽂아도 드라이버가 없으면 컴퓨터가 '이게 무슨 기계인지' 몰라서 인쇄가 안 돼요.

    !내 기기 모델명 찾기

    드라이버는 모델명으로 찾아요. 프린터는 보통 앞면이나 윗면에 모델명이 적혀 있고, 뒷면·바닥 스티커에도 있어요. 영어와 숫자를 그대로 적어 두세요.

    먼저 해 볼 것: 윈도우 자동 설치

    요즘 윈도우는 프린터를 연결하면 드라이버를 스스로 찾아 설치하는 경우가 많아요. 제조사 사이트에 가기 전에 한 번 해 보세요.

    • 설정 → Bluetooth 및 장치 → 프린터 및 스캐너에서 [장치 추가]를 눌러 프린터를 추가해요.
    • Windows 업데이트로 드라이버를 받는 방법을 Microsoft가 권장해요.
    • 그래도 안 되면 제조사 공식 사이트에서 모델명을 검색해 윈도우 버전에 맞는 최신 소프트웨어를 받아요(이 페이지의 방법).

    가짜 드라이버 사이트 조심하기

    검색 광고에 나오는 '드라이버 자동 설치' 프로그램이나 블로그에 올라온 설치 파일은 받지 마세요. 원치 않는 프로그램이나 광고가 함께 깔릴 수 있어요. 제조사 공식 사이트나 Windows 업데이트에서 받는 게 가장 안전해요.

    자주 묻는 질문

    드라이버는 꼭 설치해야 하나요?
    요즘 윈도우는 연결만 해도 기본 드라이버를 자동으로 설치하는 경우가 많아요. 다만 스캔·양면 인쇄 같은 기능까지 다 쓰려면 제조사 드라이버를 설치하는 게 좋아요.
    CD를 잃어버렸어요.
    괜찮아요. CD에 든 드라이버는 제조사 공식 사이트에서 무료로(더 새로운 버전으로) 받을 수 있어요.
    '드라이버 자동 설치' 프로그램을 써도 되나요?
    광고에 나오는 출처가 불분명한 드라이버 프로그램이나 블로그 파일은 쓰지 마세요. 원치 않는 프로그램이 함께 깔릴 수 있어요. 제조사 공식 사이트나 Windows 업데이트를 쓰세요.
    32비트, 64비트는 어떻게 골라요?
    제조사 사이트가 대부분 내 컴퓨터를 자동으로 알아봐요. 직접 골라야 하면 설정 → 시스템 → 정보에서 '시스템 종류'를 확인하세요.
    이 사이트에서 파일을 받는 건가요?
    아니요. 홍라이프 도구는 파일을 올리지 않고, 버튼을 누르면 제조사 공식 다운로드 페이지로 바로 연결돼요.
