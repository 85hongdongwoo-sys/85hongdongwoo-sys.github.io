    Microsoft Surface 드라이버 안내 원문support.microsoft.com

    업데이트 전 준비

    1. 키보드(타입 커버)·서피스 펜·도크가 있으면 연결해 두세요. 함께 업데이트돼요.
    2. 서피스를 전원에 연결하고 배터리를 40% 이상 충전해 두세요. 업데이트 중에는 전원을 꽂은 채 켜 두세요.
    3. 인터넷이 안정적인 곳에서 하세요.

    Microsoft 지원 'Surface용 드라이버 및 펌웨어 다운로드'의 'Surface 업데이트 전 준비'.

    가장 쉬운 방법: Windows 업데이트 (Microsoft 권장)

    1. 설정 → Windows 업데이트에서 [업데이트 확인]을 누르고 나온 업데이트를 설치해요.
    2. 작업 표시줄 검색창에 선택적 업데이트 보기를 입력해 열고, 드라이버 업데이트에 이름이 Surface로 시작하는 항목이 있으면 모두 설치해요.
    3. Surface 앱 → 도움말 및 지원을 펼치면 업데이트 상태를 볼 수 있어요. Surface 앱이 없으면 Microsoft Store에서 받을 수 있어요.

    직접 설치하기 (.msi 파일)

    1. 내 윈도우 빌드 확인: 키보드 윈도우 키 + R → winver 입력 → 엔터. 'OS 빌드 22631.xxxx'처럼 나와요.
    2. 아래 내 모델에서 윈도우 11용 또는 윈도우 10용 버튼을 눌러요. 버튼에 적힌 빌드 번호 이상이면 설치할 수 있어요(예: 빌드 22631 이상 → 내 빌드가 22631·26100이면 OK).
    3. 받은 .msi 파일을 두 번 눌러 실행하고, 안내대로 설치한 뒤 다시 시작해요.
    4. 내 빌드보다 높은 파일만 있으면 먼저 Windows 업데이트로 윈도우를 최신으로 올리거나, 'Microsoft 다운로드 센터'에서 다른 파일을 고르세요.

    처음 하는 분을 위한 아주 자세한 안내

    3줄 요약
    ① 내 제품 모델명을 확인해요. ② 이 페이지의 파란 버튼으로 공식 앱이나 파일을 받아요. ③ 앱에서 업데이트 확인 → 설치를 누르고, 다시 시작하라고 하면 다시 시작해요.

    1. 내 윈도우 버전 확인하기

    • 설정 → 시스템 → 정보에서 윈도우 사양(예: Windows 11, 버전 24H2)과 시스템 종류(64비트)를 볼 수 있어요.
    • 작업표시줄 검색에 winver를 쳐도 버전이 나와요.

    2. 내 서피스 제품 모델명 찾기

    • 노트북은 바닥면 스티커나 새겨진 글자, 모니터는 뒷면 스티커를 보세요.
    • 윈도우 설정 → 시스템 → 정보에도 장치 이름이 나와요.

    3. Microsoft Store 앱 설치하기

    • 파란 버튼을 누르면 Microsoft Store 페이지가 열려요. [받기] 또는 [스토어 앱에서 보기] → [받기]를 눌러요.
    • 설치가 끝나면 작업표시줄 검색에서 앱 이름을 쳐서 열어요.

    4. 파일(.exe)을 받았다면

    • 키보드 Ctrl + J로 받은 파일을 열어요. "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?"에는 [예]를 눌러요.
    • 설치 화면은 [다음] → [설치] → [마침] 순서예요.

    5. 업데이트할 때 꼭 지킬 것

    • 노트북은 충전기를 꽂고 하세요.
    • BIOS(바이오스)·펌웨어 업데이트 중에는 절대 전원을 끄거나 덮개를 닫지 마세요.
    • 여러 개를 설치한 뒤에는 다시 시작해야 적용되는 경우가 많아요.

    자주 묻는 질문

    서피스 드라이버는 꼭 따로 받아야 하나요?
    아니요. Microsoft는 대부분의 사용자에게 Windows 업데이트로 자동 설치하는 방법을 권장해요. 직접 받는 .msi 파일은 윈도우를 새로 깔았거나 업데이트가 잘 안 될 때 쓰는 고급 방법이에요.
    파일이 여러 개예요. 뭘 받아요?
    파일 이름의 Win11/Win10과 빌드 번호를 보고 내 윈도우에 맞는 것을 받아요. winver로 내 빌드를 확인하고, 그 빌드 이하 번호가 붙은 파일 중 가장 높은 것을 고르면 돼요.
    내 서피스 모델을 모르겠어요.
    Surface 앱을 열면 모델 이름이 나와요. 또는 설정 → 시스템 → 정보에서 장치 이름을 확인하세요.
    오래된 서피스도 계속 업데이트되나요?
    Microsoft 안내에 따르면 각 Surface는 '드라이버 및 펌웨어 수명 주기'에 적힌 서비스 종료 날짜까지 새 업데이트를 받아요.
    파일은 어디서 받아지나요?
    Microsoft 공식 다운로드 서버(download.microsoft.com)에서 바로 받아져요. 홍라이프 도구는 파일을 올리지 않아요.
