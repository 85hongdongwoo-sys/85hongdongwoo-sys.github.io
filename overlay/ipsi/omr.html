OMR 모의고사 채점기

기출문제를 실제 시험처럼 시간 맞춰 풀고, OMR 답안카드에 마킹한 뒤, 정답을 입력하면 몇 점인지·틀린 문항까지 바로 채점해 줘요. 어떤 시험에도 쓸 수 있어요.

시험 설정

문제지새 탭에서 열기기출 PDF를 열면 왼쪽에 문제지, 오른쪽에 OMR이 같이 떠요. (문제 창이 안 열리면 ‘새 탭에서 열기’)
⏱ 답안카드
00:00

답안카드 (OMR)

기출 PDF를 보며 문제를 풀고, 아래에서 번호를 눌러 마킹하세요. 시간이 끝나면 자동으로 채점돼요. ‘옆에 띄우기’를 누르면 PDF 창 옆에 띄워 놓고 풀 수 있어요.

정답 입력 후 채점

정답을 순서대로 입력하세요. 숫자만 붙여 써도 되고(예: 31242) 띄어쓰기·줄바꿈·쉼표로 구분해도 돼요. 기출 PDF 뒤쪽 정답표를 보고 넣으면 돼요.

OMR 모의고사 채점기 자세히 알아보기

홍라이프 도구 · 2026-11-24 업데이트

어떻게 쓰나요실전처럼 푸는 게 왜 중요한가요정답 입력은 어떻게 하나요어떤 시험에 쓸 수 있나요

어떻게 쓰나요

  1. 시험 설정 — 문항 수, 선택지(4·5지선다), 제한 시간을 정해요. 예: 한국사능력검정 50문항 80분, 공무원 9급 한 과목 20문항 20분.
  2. 시험 시작을 누르면 타이머가 돌아요. 기출 PDF를 다른 창(또는 종이)으로 보면서 문제를 풀어요.
  3. OMR 마킹 — 답을 번호판에서 눌러 마킹해요. 다시 누르면 지워져요.
  4. 시간이 끝나면 자동 채점돼요. 끝나기 전에 다 풀었으면 정답을 넣고 ‘채점하기’를 눌러요.
  5. 정답 입력 — 기출 PDF 뒤쪽 정답표를 보고 순서대로 넣어요(숫자만 붙여 써도 됨).

실전처럼 푸는 게 왜 중요한가요

기출은 그냥 눈으로 보는 것과, 시간을 재고 OMR에 마킹하며 푸는 것이 완전히 달라요. 실제 시험은 시간 압박과 마킹 실수가 점수를 크게 좌우해요.

  • 제한 시간을 걸면 ‘한 문제에 몇 초’ 감각이 생겨요.
  • OMR 마킹을 연습하면 밀려 쓰는 실수를 줄여요.
  • 채점 후 틀린 문항만 다시 보면 복습이 빨라져요.

정답 입력은 어떻게 하나요

정답을 순서대로 넣으면 돼요. 세 가지 방식 다 인식해요.

  • 숫자만 붙여서: 31242… (한 자리가 한 문항)
  • 띄어쓰기: 3 1 2 4 2 …
  • 줄바꿈·쉼표도 OK

5지선다는 정답이 5(⑤)까지 나올 수 있어요. 입력한 정답 개수가 문항 수와 맞아야 채점돼요.

어떤 시험에 쓸 수 있나요

선택형(객관식) 시험이면 뭐든 가능해요. 한국사능력검정, 공무원 9급·7급, 검정고시, 토익, 각종 자격증 필기, 모의고사까지요. 문항 수와 선택지만 맞춰 설정하면 돼요.

기출 PDF는 입시·시험 자료실에서 공식 출처로 받을 수 있어요.

자주 묻는 질문

OMR 채점기는 무료인가요?

네, 완전 무료예요. 가입도 필요 없어요. 문항 수·시간만 정하고 바로 쓰면 돼요.

정답은 어디서 구하나요?

기출문제 PDF 뒤쪽 정답표에 있어요. 그걸 보고 순서대로 입력하면 자동으로 채점돼요.

5지선다도 되나요?

네. 선택지를 5지선다로 바꾸면 ①~⑤까지 마킹과 채점이 돼요.

시간이 끝나면 어떻게 되나요?

제한 시간이 0이 되면 자동으로 채점돼요. 정답을 미리 입력해 두면 바로 점수가 나와요.

몇 문항까지 되나요?

1~200문항까지 설정할 수 있어서 공무원 100문항 같은 큰 시험도 한 번에 풀 수 있어요.
