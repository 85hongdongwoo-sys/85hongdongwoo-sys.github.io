JLPT 샘플·합격 판정

일본어능력시험(JLPT) 공식 샘플문제 받는 곳, 레벨별 합격점과 영역 기준점을 한 곳에 모았어요. 영역 점수를 넣으면 합격 여부를 바로 알려 줘요.

공식 샘플문제 받기 (무료)

JLPT는 지난 시험지를 공개하지 않지만, 공식 사이트에서 레벨별 샘플문제(유형 예시)를 무료로 제공해요. 아래가 공식 페이지예요.

JLPT 공식 문제, 어디서 받나요

JLPT는 토익처럼 실제 시험지를 공개하지 않아요. 대신 공식 사이트(jlpt.jp)에서 레벨별 샘플문제를 무료로 제공해, 문제 유형과 형식을 미리 볼 수 있어요.

  • ‘Let’s Try Sample Questions!’ — N1~N5 레벨별로 유형마다 예시 문제 1개씩 제공해요.
  • 공식 문제집(New JLPT Sample Questions, 공식 모의고사집)도 안내돼 있어요(일부는 유료 교재).
  • 실제 시험과 완전히 같지는 않지만, 유형·배점·시간 감을 잡기에 좋아요.

JLPT 레벨과 합격 기준

JLPT는 N5(가장 쉬움)부터 N1(가장 어려움)까지 다섯 레벨이에요. 총점은 180점 만점이고, 합격하려면 종합 점수가 합격점 이상이면서 모든 영역이 기준점 이상이어야 해요.

레벨종합 합격점영역 구성
N1100 / 180언어지식·독해·청해 (각 60점, 각 19점 이상)
N290 / 180언어지식·독해·청해 (각 60점, 각 19점 이상)
N395 / 180언어지식·독해·청해 (각 60점, 각 19점 이상)
N490 / 180언어지식·독해(120점, 38점 이상) + 청해(60점, 19점 이상)
N580 / 180언어지식·독해(120점, 38점 이상) + 청해(60점, 19점 이상)

예를 들어 N2에서 총점 95점이어도 청해가 18점이면 기준점(19점) 미달이라 불합격이에요. 위 판정기로 영역별 기준까지 한 번에 확인하세요.

시험은 언제, 어디서 보나요

JLPT는 한국에서 보통 연 2회(7월·12월) 치러요. 접수와 일정은 국내 시행 기관 안내를 따르고, 레벨은 한 회차에 하나만 선택해요.

점수 보고서에는 2025년부터 참고용 CEFR 등급도 함께 표기돼요. 유효기간이 따로 없지만, 기관·학교에서 보통 2년 이내 성적을 요구하는 경우가 많아요.

공부 순서 추천

  • 먼저 목표 레벨의 샘플문제로 유형(문자·어휘·문법·독해·청해)을 확인해요.
  • 언어지식(문자·어휘·문법)에서 점수를 쌓고, 독해·청해는 시간 배분 연습이 중요해요.
  • 영역 하나가 기준점에 못 미치면 전체가 불합격이라, 약한 영역을 기준점 이상으로 끌어올리는 걸 우선해요.

자주 묻는 질문

JLPT 기출문제를 받을 수 있나요?

실제 시험지는 공개되지 않아요. 대신 공식 사이트 jlpt.jp에서 레벨별 샘플문제(유형 예시)를 무료로 받을 수 있어요.

JLPT는 몇 점이면 합격인가요?

N1 100점, N2 90점, N3 95점, N4 90점, N5 80점(180점 만점) 이상이면서, 모든 영역이 기준점(보통 19점, N4·N5 언어지식·독해는 38점) 이상이어야 합격이에요.

한 영역 점수가 낮으면 어떻게 되나요?

종합 점수가 합격점을 넘어도, 한 영역이라도 기준점 미만이면 불합격이에요.

JLPT는 1년에 몇 번 보나요?

한국에서는 보통 7월과 12월, 연 2회 치러요.
