르노코리아 내비게이션·openR link 업데이트 방법

르노코리아 내비·소프트웨어를 최신으로 바꾸는 방법을 그림으로 쉽게 정리했어요.

openR link 소프트웨어는 새 버전이 있으면 주행 중 무선으로 자동 다운로드되고, 시동을 끄면 설치할지 묻는 창이 떠요. [예]를 누르면 끝이에요. openR link 9.3인치(세로형) 지도는 TMAP 공식 페이지에서 파일을 받아 16GB 이상, FAT32 USB 맨 위 폴더에 넣고 차에 꽂으면 자동으로 업데이트돼요.

소프트웨어: 무선으로 자동 (openR link)

1주행하면 저절로 받아져요

새 소프트웨어가 있으면 차가 주행 중에 알아서 내려받아요. 받는 동안에도 내비와 멀티미디어는 그대로 쓸 수 있어요.

주행 시간이 짧으면 다음 주행 때 이어서 받아요.

2시동 끄고 [예] 누르기

다 받으면 시동을 끌 때 설치할지 묻는 창이 떠요. [예]를 누르면 운전자 없이 설치가 진행되고, 끝나면 시스템이 저절로 꺼져요.

지도: openR link 9.3인치 세로형 (USB)

3TMAP 공식 페이지에서 지도 받기

TMAP 모빌리티 공식 페이지에서 르노코리아 openR link 9.3" 지도 파일을 받아 압축을 풀어요. 그러면 TMAP 폴더가 생겨요.

4USB 맨 위에 TMAP 폴더 넣기

16GB 이상 USB를 FAT32로 포맷한 뒤, TMAP 폴더를 USB 맨 위(루트)에 복사해요.

8GB 이하 USB는 설치가 제대로 안 될 수 있다고 공식 안내에 적혀 있어요.

5차에 꽂으면 자동 업데이트

차의 USB 단자에 꽂으면 지도 업데이트가 자동으로 진행돼요.

공식 사이트 바로가기

르노코리아 openR link 무선 업데이트 안내openR link 9.3" 지도 업데이트 (TMAP 공식)

출처: 르노코리아 공식 사이트(renault.co.kr) connectivity 차량관리 안내, TMAP 모빌리티 르노코리아 openR link 9.3" 지도 업데이트 안내 · 확인 2026년 11월 21일. 그림은 이해를 돕기 위해 단순하게 그린 것이라 실제 화면과 다를 수 있어요.

자주 묻는 질문

openR link 업데이트는 직접 해야 하나요?
아니요. 새 소프트웨어가 있으면 차가 주행 중 알아서 받고, 시동을 끌 때 설치할지 물어요. [예]만 누르면 돼요.
지도 업데이트 USB는 몇 GB가 필요해요?
TMAP 공식 안내는 16GB 이상을 권장하고, FAT32로 포맷하라고 해요. 8GB 이하는 설치가 안 될 수 있어요.
문의는 어디로 하나요?
르노코리아 엔젤센터 080-300-3000이에요(공식 사이트 기재). 지도 파일 문의는 TMAP 앱 마이 → 고객센터 → 1:1 문의로 하라고 TMAP 공식 페이지에 안내돼 있어요.
