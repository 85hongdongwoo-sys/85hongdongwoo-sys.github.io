기아 내비게이션 업데이트 방법

기아 순정 내비 지도와 소프트웨어를 최신으로 바꾸는 방법을 그림으로 쉽게 정리했어요. 차 한 번, PC 한 번이면 끝나요.

기아 커넥트(Kia Connect, 옛 UVO)에 가입한 차는 업데이트가 무선으로 자동 내려와요(도착 시점은 통신·차량 상태에 따라 달라요). 가입하지 않았거나 빨리 받고 싶다면, PC에 Navigation Updater를 깔고 32GB 이상 USB 메모리나 SD 카드(exFAT)에 파일을 받아 차에 꽂으면 돼요. 차에서는 설정 → 일반 → SW 정보/업데이트 → 업데이트를 누르세요.

그림으로 보는 업데이트 순서 (5단계)

1PC에 업데이트 프로그램 깔기

기아 공식 업데이트 사이트에서 Navigation Updater를 받아 설치해요. 윈도우용과 맥용이 따로 있어요.

맥에서 "확인되지 않은 개발자" 창이 뜨면 시스템 설정 → 보안 및 개인 정보 보호에서 "확인 없이 열기"를 누르면 돼요.

2내 차 고르고 다운로드 누르기

사이트 첫 화면의 [내 차 맞춤 업데이트 조회]에서 차종을 고르고 [다운로드]를 누르면 설치한 프로그램이 열려요. 회원가입을 안 해도 비회원 메뉴로 받을 수 있어요.

3USB·SD 카드에 복사하기

프로그램에서 받을 위치를 정하고 다운로드가 끝나면 [USB로 복사]를 눌러요. 처음부터 USB·SD 카드를 저장 위치로 골랐다면 이 단계는 건너뛰어요.

PC에서 USB가 "로컬 디스크"로 보이면 복사가 안 될 수 있어요. 다른 USB를 쓰세요.

4차에 꽂고 업데이트 누르기

차에 USB 메모리나 SD 카드를 꽂고 내비 전체 메뉴 → 설정 → 일반 → SW 정보/업데이트에서 [업데이트]를 눌러요.

오래된 내비는 메뉴 이름이 조금 달라요(예: 표준형 1·2세대는 SW 정보 → USB 업데이트). 공식 이용가이드의 내비 종류별 방법을 함께 보세요.

5끝날 때까지 기다리기

업데이트 중에는 전원을 끄거나 USB·SD를 빼면 안 돼요. 끝나면 내비가 저절로 다시 켜지고 버전이 바뀌어요.

시동 버튼 ON 상태로 한다면 배터리가 충분한지 먼저 확인하세요. 겨울이나 오래 안 탄 차는 방전되기 쉬워요.

USB인지 SD 카드인지 확인하기

내비 종류에 따라 꽂는 저장장치가 달라요. 내 차 내비 종류는 공식 사이트에서 차종을 고르면 알려줘요.

필요한 것내비 종류 (공식 안내)
USB 메모리고급형 1세대, 고급형 5세대, 고급형 6세대, 표준형 5W세대, ccNC, 표준형 1·2세대 (DVD 포함)
SD 카드고급형 2세대, 표준형 3세대, 표준형 4세대, 표준형 5세대, 경제형 5세대

준비물 체크

  • 용량 32GB 이상 (공식 권장)
  • exFAT 형식 — 형식이 다르면 내비가 못 알아볼 수 있어요
  • SD 카드는 UHS-I(초당 10MB 이상) 권장
  • 일부 내비는 USB-C 타입이 필요해요
  • PC (윈도우 또는 맥) + 인터넷

USB·SD 문제로 생긴 데이터 손실은 제조사 책임 범위가 아니라고 공식 안내에 적혀 있어요. 중요한 파일이 든 USB는 쓰지 마세요.

빌트인 캠(블랙박스) 업데이트

✓빌트인 캠 1: USB로 직접 업데이트

공식 사이트 [내 차 맞춤 업데이트 조회]에서 빌트인 캠 파일을 받아 압축을 풀지 말고 그대로 USB 최상위 폴더에 넣어요. 내비 USB 단자가 아닌 빌트인 캠 전용 USB 단자에 꽂고, 전체 메뉴 → 빌트인 캠 → 빌트인 캠 설정 → 업데이트를 눌러요.

업데이트 중에는 시동을 켜고 기어를 P에 두세요. 그동안 녹화는 안 돼요. USB는 FAT16·FAT32·NTFS·exFAT 모두 돼요.

빌트인 캠 1 적용 차종

  • EV6
  • 더 뉴 셀토스
  • 3세대 K5 (하이브리드 포함)
  • 디 올 뉴 기아 니로 (EV 포함)
  • K7 Premier (하이브리드 포함)
  • 스포티지 (하이브리드 포함)
  • K8 (하이브리드 포함)
  • 4세대 쏘렌토 (하이브리드 포함)
  • K9
  • 4세대 카니발

빌트인 캠 2는 무선(OTA)으로 시동을 켤 때 자동 업데이트돼요. 기아 커넥트(Kia Connect, 옛 UVO)에 가입해야 하고, 내비를 USB로 수동 업데이트하면 빌트인 캠 2도 함께 업데이트돼요.

  • EV9
  • 더 뉴 K5 (하이브리드 포함)
  • EV6
  • 더 뉴 카니발 (하이브리드 포함)
  • 더 뉴 쏘렌토 (하이브리드 포함)

무선 업데이트(OTA)는 언제 되나요?

기아 커넥트(Kia Connect, 옛 UVO) 적용 차량이고 서비스에 가입했다면, 새 업데이트가 있을 때 시동을 걸면 자동으로 업데이트돼요. 일부 오래된 차종은 무선 업데이트 지원이 끝났으니 공식 사이트에서 내 차를 확인하세요.

공식 사이트 바로가기

파일은 아래 기아 공식 업데이트 사이트에서만 받으세요.

내비게이션 이용가이드업데이트 소식(새 버전)빌트인 캠 가이드무선 업데이트 가이드

자주 묻는 질문

기아 내비 업데이트는 돈이 드나요?
공식 사이트와 Navigation Updater는 무료예요. 다만 지도 업데이트 무료 기간이 차량·내비마다 정해져 있어요. 예를 들어 현대 표준형 5세대 내비 사용 설명서에는 "차량 구매 후 8년까지 보장"이라고 적혀 있어요. 내 차 기간은 공식 사이트나 사용 설명서에서 확인하세요.
USB가 인식이 안 돼요.
32GB 이상, exFAT 형식인지 확인하세요. PC에서 USB가 이동식 디스크가 아니라 로컬 디스크로 보이면 복사가 안 될 수 있어요. 다른 USB로 바꿔 보는 게 가장 빨라요.
업데이트는 얼마나 걸리나요?
데이터 양에 따라 수십 분이 걸릴 수 있어요. 시간이 넉넉할 때, 배터리가 충분할 때 하세요.
업데이트 중에 시동이 꺼지면 어떻게 되나요?
전원이 끊기거나 USB·SD를 빼면 내비가 제대로 작동하지 않을 수 있어요. 꼭 끝날 때까지 기다리세요. 문제가 생기면 공식 고객센터나 서비스센터에 문의하세요.
회원가입을 해야 하나요?
아니요. 공식 사이트의 비회원 메뉴로도 업데이트 파일을 받을 수 있어요. 로그인하면 내 차 정보가 저장돼 다음부터 편해요.
