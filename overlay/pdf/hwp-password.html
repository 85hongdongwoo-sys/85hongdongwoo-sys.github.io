HWP 암호 걸기·풀기

한글 문서에 열기 암호를 걸거나, 암호를 아는 문서의 암호를 풀어 저장해요. 한컴오피스가 없어도 돼요.

파일은 서버로 전송되지 않고 내 기기에서만 처리돼요
원본 파일은 꼭 따로 두세요. 오픈소스 엔진(rhwp)이 문서를 다시 저장하면서 암호를 걸어요. 중요한 문서는 받은 파일을 한글에서 한 번 열어 암호가 잘 걸렸는지 확인하세요. 암호를 잊으면 아무도 열 수 없어요.

한글 문서에 암호를 거는 경우암호 걸기와 풀기사용 방법한글 프로그램에서 직접 걸려면

한글 문서에 암호를 거는 경우

  • 개인정보(주민번호·연락처)가 든 명단·신청서를 메일이나 메신저로 보낼 때
  • 인사·급여·평가 자료처럼 받는 사람만 봐야 하는 문서
  • 기관 지침에 ‘개인정보 파일은 암호를 걸어 보내라’고 되어 있을 때

암호는 메일 본문이 아니라 문자나 전화처럼 다른 길로 알려 주는 게 안전해요.

사용 방법

  1. 위에서 ‘암호 걸기’ 또는 ‘암호 풀기’를 골라요.
  2. 파일을 놓고 암호를 적어요. 걸 때는 같은 암호를 두 번 적어요.
  3. 버튼을 누르면 새 파일이 받아져요. 원본은 바뀌지 않아요.

한글 프로그램에서 직접 걸려면

한글에서 [보안] → [문서 암호 설정](또는 [파일] → [문서 암호])에서 걸고, 같은 메뉴의 [문서 암호 변경/해제]에서 풀어요. 한글이 없는 컴퓨터나 휴대전화에서는 이 페이지를 쓰면 돼요.

자주 묻는 질문

한글 파일 암호를 잊어버렸어요. 풀 수 있나요?

아니요. 이 페이지는 암호를 아는 문서만 풀 수 있어요. 암호를 찾아 주거나 뚫는 기능은 없고, 그런 방법도 안내하지 않아요. 원본을 만든 사람에게 암호 없는 파일을 다시 받으세요.

암호를 걸면 휴대전화에서도 열리나요?

한컴오피스 뷰어 앱처럼 암호 문서를 지원하는 앱에서 암호를 넣으면 열려요.

적은 암호가 어딘가에 저장되나요?

아니요. 암호와 파일은 이 브라우저 안에서만 쓰이고 서버로 가지 않아요. 파일을 받은 뒤 입력칸도 바로 비워요.

배포용 문서(복사·인쇄 막기)도 되나요?

배포용 문서 설정은 한글 프로그램의 [보안] → [배포용 문서로 저장]에서 해요. 이 페이지는 열기 암호만 다뤄요.

다른 한글(HWP) 도구

  • HWP 뷰어 (한글 파일 열기)한컴오피스 없이 HWP·HWPX 보기, 글자 복사·인쇄
  • HWP를 PDF로 변환여러 개 한 번에, 검색·복사 되는 PDF
  • HWP를 HWPX로 변환옛 한글 파일을 새 형식으로, 여러 개 ZIP
  • HWPX를 HWP로 변환옛 버전 한글에서도 열리게
  • HWP 텍스트 추출글자만 TXT로, 글자 수·원고지 매수
  • 텍스트·워드를 한글 파일로TXT·DOCX → HWP·HWPX 만들기
  • HWP를 그림(PNG·JPG)으로쪽마다 한 장, 카톡·블로그용
  • HWP를 워드(DOCX)로워드·구글 문서에서 열리게
  • 엑셀·CSV를 한글 표로복사한 표도 HWP 표로
  • HWP 표를 엑셀로문서 안 표를 XLSX·CSV로
  • HWP 그림 꺼내기넣은 사진을 원본 그대로
  • 한글 문서 비교두 파일의 달라진 줄 찾기
  • HWP 개인정보 찾기주민번호·전화번호 확인
